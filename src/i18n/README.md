# 网站语言

- 简体中文使用原路径，英文使用 `/en/`，繁体中文使用 `/zh-Hant/`。
- 语言下拉菜单保留页面、查询参数和锚点；站内导航沿用当前语言。
- `en.ts` 和 `finone.ts` 保留已有英文，`translations.ts` 补充有实际入口页面的英文与繁体。隐藏及旧版对比页面不在本次翻译范围。
- React 文案使用 `t()`；动态 React 子节点使用 `translateNode()`，仅处理字符串和字符串数组，不修改组件或实时 DOM。
- `localizedHref()` 只用于站内页面链接。图片、SVG image、视频、API、路由 ID、表单值和业务判断不得翻译。
- HTML 模板由 `translateMarkup()` 在渲染前转换文本及可访问名称。
- 新增文案时同时补充英文和繁体词条。已有英文优先于补充词表。
- AI 问候语跟随网站语言；生成的回答和链接 label 由 AI 根据用户语言判断，前端不再翻译。href 仍使用官网白名单。
