# 逐页补充多语言

- 中文地址保持不变，英文地址以 `/en/` 开头。
- `index.ts` 从 URL 选择语言，提供 `t()`、内部链接前缀与旧 HTML 模板的文本翻译。
- `en.ts` 是当前公共区域与首页的英文文案表，以原中文为键。客户无核验英文名称时保留中文品牌名。
- React 页面使用 `t('中文原文')`，动态文案使用 `t(value)`；链接用 `localizedHref()`。不要翻译图片路径、路由 ID、业务判断条件。
- `Markup` 在渲染前翻译模板文本和可访问名称，不修改 React 管理的实时 DOM。
- 增加下一页英文时：补齐文案表、在对应页面接入 t、调整英文长文案排版，再将 SiteLayout 的待翻译提示条件排除该页面。
- 切换按钮始终保留；未翻译页面仍能通过 /en/ 访问，显示待翻译提示和原中文内容。语言切换重新加载对应 URL，浏览器刷新和前进后退均以地址为准。
- 首屏、导航与数字动画共用原组件。英文布局适配集中在 `src/styles/global/english.css`。
